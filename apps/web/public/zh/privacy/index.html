隐私政策

定位与导航

获得你的系统权限后，Waybi 使用定位显示位置、计算路线、跟随行程并提供导航提醒。导航期间，锁屏或切到后台后可能继续使用定位和音频权限；你可以在设备设置中调整。搜索和算路会把相关搜索词、起终点、途经点，以及部分请求中的附近坐标发送给完成请求所需的服务。即使未登录，位置信息仍然敏感。

账号与保存的信息

基础地图和导航无需注册账号。创建账号后，我们保存邮箱、账号标识、密码账号的盐值和密码哈希、偏好，以及你选择保存或同步的信息。相关信息可能包括家和公司的坐标、最近目的地、收藏地点、行程记录、地点备注/评价、旅伴日记和旅行统计。Google 或 Apple 登录使用其提供的账号标识，Waybi 不接收你的 Google 或 Apple 密码；Apple 登录仅在完成相关配置后可用。

本机数据与云同步

App 在设备上保存设置和导航状态，并使用安全存储保存账号会话。实时 GPS 更新主要用于本机导航，不作为持续实时追踪流上传。这不代表定位从不离开设备：算路、保存地点、已完成行程、道路报告和账号备份可能含有位置。Route Watch 在服务器检查已保存的路线走廊，而非持续跟踪你的当前位置。

服务商及跨境处理

Cloudflare 提供网站、API、账号数据库和缓存；Google Cloud 托管 Waybi 的新西兰私有 Valhalla 路由服务。Google Places UI Kit 在可用时提供 Google 地点搜索。根据地区和所用功能，请求也可能发送给独立地图、搜索、路线、公交或官方道路数据服务，包括 OpenFreeMap 和基于 OpenStreetMap 的服务。Waybi 自研地图使用独立底图与路线服务。网页版不加载 Google Maps SDK，使用 Waybi 托管的新西兰地图瓦片、OpenFreeMap 和独立搜索及路线服务。服务商可能处理 IP 地址、请求详情和技术日志，并可能在新西兰以外处理数据；其自身服务适用其隐私政策。

用量、日志、报告与支持

Waybi 记录 API 用量和配额计数，以维护可靠性和控制成本。托管或上游服务可能处理 IP、时间、错误和请求元数据。社区道路报告包含位置、类型和时间，用于向附近用户显示事件；请勿在报告中填写他人的隐私。导航反馈可能包含路线详情或坐标。联系支持时，我们会收到邮件、联系方式及你自愿发送的附件；支持邮件会转发至运营者的支持收件箱。

付款

订阅启用后，iOS 付款由 Apple 处理，Waybi 保存交易标识、产品和会员状态以验证及恢复权益，不接收 Apple 付款中的完整银行卡资料。未来网页付款渠道可能使用 Stripe 的托管付款页，相关功能需另行配置。删除 Waybi 账号不会自动取消 App Store 订阅，请在 Apple 账号中管理订阅。

保存期限与删除

为提供账号和所选功能，已保存信息会保留至你修改、删除或服务不再需要该信息；当前服务对最近地点和历史行程数量设有限制。会话会过期，退出或删号时会撤销相应会话。登录后可在“我的”选择“删除账号”并确认邮箱，删除当前账号和关联云记录，并清理该删除流程处理的本机账号数据。服务商日志、支持往来、支付平台记录和恢复副本可能各有保存期限，删除当前账号不表示所有日志或备份会立即消失。无法在 App 中处理的信息，请联系支持。

你的选择与联系方式

你可以不注册就使用基础导航，调整定位、音频和通知权限，修改保存信息、退出或删除账号。有关数据访问、更正、保存期限或隐私问题，请联系 support@waybi.co；我们可能需要核实请求对应你自己的信息。请勿通过邮件发送密码、验证码或完整出行轨迹。服务变化时我们会更新本政策，并在此显示更新日期。
